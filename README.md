# Гимназическая мини-футбольная лига

Полноценный веб-сайт для школьной/гимназической мини-футбольной лиги.

## Возможности

- **Команды и игроки** — добавление, эмблемы, составы
- **Гибкое расписание** — генератор для круговой, групповой, плей-офф систем
- **Автоматическая турнирная таблица** — очки, разница мячей, сортировка
- **Статистика** — лучшие бомбардиры, ассистенты, вратари (по сухим матчам)
- **Админ-панель** — только для роли `admin`, остальные пользователи только смотрят
- **Генератор афиш** — красивые постеры туров с эмблемами команд (PNG)
- **Авторизация** через Supabase Auth

## Стек

| Технология | Назначение |
|------------|------------|
| Next.js 14 (App Router) | Frontend + API |
| TypeScript | Типизация |
| Tailwind CSS | Стили |
| Supabase | БД, Auth, Storage |
| Vercel | Хостинг |
| html2canvas | Генерация афиш |

## Подробная инструкция по созданию и запуску

### Шаг 1. Создайте аккаунт Supabase

1. Зайдите на https://supabase.com и зарегистрируйтесь.
2. Нажмите **New Project**.
3. Выберите организацию, введите название (например `mini-football-league`), задайте пароль БД, регион (ближайший).
4. Дождитесь создания проекта (~1–2 минуты).

### Шаг 2. Получите ключи API

1. В панели Supabase откройте **Project Settings → API**.
2. Скопируйте:
   - **Project URL**
   - **anon public** ключ

### Шаг 3. Создайте схему базы данных

1. В Supabase откройте **SQL Editor**.
2. Создайте новый запрос.
3. Скопируйте **весь** содержимое файла `scripts/schema.sql` и выполните (Run).
4. Убедитесь, что ошибок нет.

### Шаг 4. Создайте бакет Storage для эмблем

1. Перейдите в **Storage**.
2. Нажмите **New bucket**.
3. Имя: `emblems`.
4. Поставьте галочку **Public bucket**.
5. Создайте.

### Шаг 5. Создайте первого администратора

1. В Supabase откройте **Authentication → Users**.
2. Нажмите **Add user → Create new user**.
3. Введите email и пароль.
4. После создания зайдите в **Table Editor → profiles**.
5. Найдите свою запись и измените `role` с `viewer` на `admin`.

> Альтернатива: зарегистрируйтесь через сайт, затем вручную поменяйте роль в таблице `profiles`.

### Шаг 6. Установите зависимости

```bash
cd mini-football-league
npm install
```

### Шаг 7. Настройте переменные окружения

```bash
cp .env.local.example .env.local
```

Откройте `.env.local` и вставьте:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### Шаг 8. Запустите локально

```bash
npm run dev
```

Откройте http://localhost:3000

### Шаг 9. Первичная настройка данных

1. Войдите под админом (/auth/login).
2. Перейдите в **Админ → Настройки сезона**.
3. Создайте сезон (например «Сезон 2025/26», система «Круговая»).
4. **Админ → Команды** — добавьте команды, загрузите эмблемы.
5. **Админ → Игроки** — добавьте составы.
6. **Админ → Расписание** — сгенерируйте и сохраните.
7. **Админ → Матчи** — указывайте даты/время и результаты + события (голы, ассисты).

Таблица и статистика обновляются автоматически!

## Деплой на Vercel + GitHub

### 1. Создайте репозиторий на GitHub

```bash
git init
git add .
git commit -m "Initial commit: mini-football league"
git branch -M main
git remote add origin https://github.com/ВАШ_ЮЗЕР/mini-football-league.git
git push -u origin main
```

### 2. Подключите к Vercel

1. Зайдите на https://vercel.com и войдите через GitHub.
2. **Add New Project** → выберите репозиторий.
3. В **Environment Variables** добавьте:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Нажмите **Deploy**.

Через 1–2 минуты сайт будет доступен по адресу https://ваш-проект.vercel.app
